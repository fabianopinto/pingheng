# Contributing to Pínghéng

Thank you for your interest in contributing to Pínghéng! We welcome contributions from the community to help make this tool better for everyone.

## How to Contribute

### Reporting Bugs

- Search the [Issue Tracker](https://github.com/fabianopinto/pingheng/issues) to see if the bug has already been reported.
- If not, create a new issue. Provide a clear description of the problem, steps to reproduce it, and your environment (device, Android version).

### Suggesting Enhancements

- If you have an idea for a new feature or improvement, please open a new issue and describe your suggestion in detail.

### Pull Requests

1.  **Fork the repository** on GitHub.
2.  **Create a new branch** from `main` for your changes: `git checkout -b feature/your-feature-name` or `bugfix/your-bug-fix`.
3.  **Make your changes** and ensure the code follows the existing style and best practices.
4.  **Write clear and concise commit messages**.
5.  **Push your branch** to your fork: `git push origin your-branch-name`.
6.  **Open a Pull Request** against the `main` branch of the original repository.

### Code Style

- Follow the [Kotlin Coding Conventions](https://kotlinlang.org/docs/coding-conventions.html).
- Use [Jetpack Compose Best Practices](https://developer.android.com/jetpack/compose/performance).
- Ensure your code is well-commented where necessary.

## Community

If you have any questions or want to discuss the project, feel free to open a [Discussion](https://github.com/fabianopinto/pingheng/discussions) on GitHub.
